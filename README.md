# Team Project Version Control

## Project Description
Team project repository for version control and branch workflow practice.

## Modules
- Login Module
- Product Module

## Workflow
1. Create a repository.
2. Create branches for individual modules.
3. Add and commit files.
4. Create pull requests.
5. Review and merge branches.
6. Resolve merge conflicts.

## Tools Used
- GitHub
- Git

## Result
Successfully implemented version control using GitHub branches and pull requests.
